# 2026 九合一選舉預測大賽｜計分規則

- **縣市長（每區滿分 100 分）**：
  - 猜中當選人：**+40 分**，並加計得票率精準度（最高 **+60 分**）：`max(0, 60 - |預測得票率 - 實際得票率| × 4)`，誤差越小分數越高。
  - 若候選人預測錯誤，該區直接 **0 分**（不計得票率精準度分數）。
- **桃園區議員特別題（滿分 60 分）**：
  - 預測 12 號「王妃」會不會當選，預測成功即 **+60 分**。
- **排名方式**：
  - 依總分由高至低排序；同分時以命中題數較多者勝出，若仍相同則以命中縣市長之得票率總誤差較小者勝出（完全相同則並列名次）。
